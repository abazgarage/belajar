# AB Garage — Website Pembelajaran Otomotif

Website statis responsif dengan 4 tab: Beranda, Materi, Kalkulator, dan Simulasi.

## Menjalankan
1. Ekstrak folder proyek.
2. Buka `index.html` di browser, atau unggah semua file ke repositori GitHub.
3. Untuk GitHub Pages: buka **Settings → Pages**, pilih branch `main` dan folder `/ (root)`, lalu simpan.

## File
- `index.html` — struktur dan isi halaman
- `style.css` — desain responsif
- `script.js` — navigasi tab, materi, kalkulator, dan simulasi

Kalkulator dan materi ini untuk pembelajaran. Untuk servis nyata, selalu gunakan spesifikasi dan prosedur pabrikan kendaraan.
